# Reactivate v0.14 — Content Intelligence / PatternVault

## Goal
Turn saved content inspiration into reusable structural knowledge, then use that knowledge to generate original, prospect-specific content concepts.

## Guardrails
- Store source URL when available.
- Never present copied source text as original content.
- Separate source pattern from generated concept.
- Never invent performance results.
- If Social Gap is unverified, label concepts as general ideas rather than reactivation claims.

## Flow
Save inspiration → capture pattern → store/search PatternVault → combine pattern + prospect evidence → generate original concepts → human review.
