# NahaLabs Reactivate v0.18 — Content Production Pipeline

## Goal
Move approved content assets into explicit production briefs without pretending that media rendering or external generation has occurred.

## Flow
Approved content asset → production brief → shot list / voiceover / CTA → production status → future renderer → publishing queue.

## Guardrails
- Only REVIEW, APPROVED, or PRODUCED assets can create production jobs.
- Real footage and verified claims only.
- Rendering is explicitly NOT_CONFIGURED in this release.
- No automatic publishing.
