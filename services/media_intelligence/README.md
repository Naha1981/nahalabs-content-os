# Media Intelligence Engine

Provider-agnostic analysis pipeline for ordinary phone footage. Green-screen input is optional, never required.

Pipeline:
1. media metadata / technical quality
2. audio extraction + transcription
3. scene / shot detection
4. subject and product segmentation
5. OCR
6. visual + audio semantic understanding
7. normalized Content Understanding Object
8. enqueue strategy generation

The engine must preserve source media and store analysis as versioned, auditable artifacts.
