# NahaLabs Reactivate v0.29 — Outreach + Campaign Command Center

## Goal
Unify seller outreach state with campaign execution so the operator can see whether a prospect has been queued, contacted, replied, or otherwise engaged while the reactivation campaign progresses.

## Scope
- Persist outreach events independently from current prospect status.
- Expose outreach history per prospect.
- Surface event count and latest outreach event/channel in the Campaign Command Center.
- Keep outreach actions human-controlled; no automatic sending.

## Guardrails
- Public contact details only.
- No guessed decision makers or private data.
- Logging an event is not proof of a response or commercial outcome.
- Live channel sending remains credential-gated and outside this release.
