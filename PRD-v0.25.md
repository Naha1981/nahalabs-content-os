# NahaLabs Reactivate v0.25 — Automated Learning → Content Engine

## Goal
Turn observed publishing performance into transparent, reusable content-generation guidance.

## Rules
- No causal claims from small samples.
- Learning signals are explicitly labeled observed signals.
- No performance data means no invented strategy.
- Existing evidence/verification rules remain unchanged.

## Flow
Performance observations → learning engine → content brief → content generation → human review → production.

## Local scope
SQLite learning summaries and deterministic template generation. External platform analytics and AI providers remain adapters for later versions.
